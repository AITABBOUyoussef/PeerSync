# PeerSync - ENAA 🚀

PeerSync est une plateforme d'entraide dédiée aux apprenants de l'Ecole Numérique Ahmed El Hansali, permettant de mettre en relation des apprenants bloqués avec des tuteurs volontaires.

## 🛠 Technologies Utilisées
- **Backend:** PHP 8+ (Orienté Objet)
- **Architecture:** MVC & Repository Pattern (Typage Strict, Encapsulation)
- **Base de données:** MySQL (PDO)
- **Frontend:** HTML5, Tailwind CSS
- **Gestionnaire de dépendances:** Composer (Autoloading PSR-4, Dotenv)
